# Versioning

The specification version describes bundle semantics. Phase 1 freezes the v0.1 draft contract as specification version `0.1`. The current Rust, TypeScript, and Python implementations pass the shared semantic fixture catalog, and the hosted Core run `37919776037` verifies all 12 directed interoperability paths across Ubuntu and Windows. This evidence covers the current implementations and recorded fixtures; it does not certify future integrations or every possible implementation. Each implementation has its own package/CLI version. Repository tags identify coordinated snapshots but do not make package patch versions identical. Additive optional metadata is compatible; required-field or interpretation changes require a new specification major version. Implementations MUST reject unsupported future major versions and MAY preserve unknown extension fields under `extensions`.
